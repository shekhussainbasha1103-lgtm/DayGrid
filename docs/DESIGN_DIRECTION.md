# Daygrid visual direction

- Visual identity: futuristic comic-book campus, playful but readable.
- Current build: dark/light themes, violet default accent, selectable cyan/coral/lime accents, rounded cards, icon-led sections.
- Planned polish: custom illustrated mascot, speech-bubble callouts, comic-panel home cards, collectible semester quests, haptics, full font-family picker, and persistent theme preferences.
- Keep text contrast accessible; never use decorative fonts for attendance percentages, dates, marks, or other critical information.
