# Daygrid screenshot-inspired feature update

Added prototype sections inspired by the uploaded reference screenshots:
- Updates timeline with All / Attendance / Marks / Notices filters
- CGPA / SGPA estimate explanation
- Events and clubs
- Notes and exam timetable
- eCurriculum solver
- Existing app sections already include attendance margin calculations, marks estimates, mess menu by weekday and meal, faculty finder placeholder, OD/ML planner, campus/hostel profile, personalization and portal links.

## Important limitations
These screens are UI prototypes and use sample content. They do not access SRMIST private records, scrape the student portal, or provide live updates. Real attendance/marks/notices synchronization requires an authorized API or integration approved by SRMIST. Push reminders, persistent storage, PDF uploads, event registration, and map routing need additional implementation and testing.

Never store SRM NetID passwords or OTPs in the app. Verify all faculty, classroom, exam, hostel and mess details from official sources before relying on them.
